# 무효 처리한 편집 산출물

두 번째 맹검 시도의 run 2 편집자가 결과 보고에서 `humanizer-ko` 기준을 사용했다고 명시했다. 이 평가는 `korean-prose-editor`의 `editing-policy.md`만 편집 정책으로 제공해야 하므로 다른 한국어 편집 스킬의 사용 여부를 확인할 수 없는 후보는 역할 입력 격리 조건을 충족하지 않는다.

동일한 지시와 환경에서 작성된 run 1 후보도 오염되지 않았다고 입증할 수 없어 함께 무효 처리했다. selection 결과는 허용 입력만 사용했으므로 유지한다. 후보와 그 후보에서 만든 verification 입력은 이 디렉터리에 보존하며 지표에 사용하지 않는다. 새 편집 실행에는 다른 산문 편집 스킬을 호출하거나 읽지 말라는 사용자 고정 경계를 명시한다.
